# 스프라이트를 바꿨을 때 위치·크기를 고칠 오브젝트 목록

그림(스프라이트)을 새로 넣거나 크기·피벗(기준점)·PPU를 바꾸면, 아래 오브젝트의 충돌·판정 위치와 크기를 눈으로 다시 맞춰야 한다.
이 문서는 **어디를 고쳐야 하는지** 찾는 목록이다(구조 설명은 `unity-architecture.md`).

- 모든 값은 **월드 단위**다(1유닛 = 100px 기준. 그림이 얼마나 크게 보이는지는 스프라이트의 **PPU**에 따라 달라지므로 그림을 바꾸면 PPU부터 확인한다).
- "현재 값"은 **2026-10-18 `SampleScene` 기준**이다. 고치고 나면 이 표의 값도 같이 고친다.
- 새 충돌체나 그림에 맞춰야 하는 오프셋을 만들면 **이 표에 한 줄 추가**한다(맨 아래 "목록에 넣는 규칙").

## 고치는 순서

1. **기준점부터**: 플레이어의 `Visual` 위치(아래 A-1)를 먼저 맞춘다. 발이 `Player` 위치(땅)에 오게 둔다. 아래 오프셋 대부분이 "그림 한가운데" 기준으로 잡혀 있다.
2. **위에서부터 차례로** A → B → C → D → E. 오브젝트를 선택하고 Scene 뷰에서 콜라이더의 초록 테두리를 보며 `Edit Collider` 버튼(또는 Alt를 누른 채 드래그)이나 인스펙터의 Offset/Size 숫자로 고친다.
3. 다 맞추면 아래 "맞춘 뒤 확인"을 한 번 돌려 본다.

> 새 플레이어를 메뉴(`GameObject ▸ Hangeul ▸ Player`)로 만들면 발밑 상자는 **추정값**(크기 0.16×0.08, 오프셋 (0, -0.10))으로 들어간다. 반드시 그림에 맞춰 고친다.

## 자동으로 맞춰지는 것 (손대지 않아도 되지만 확인은 한다)

- **적 머리 위 속성 글자("화염!")**: 맞은 대상의 첫 번째 렌더러 꼭대기 높이를 읽어 그 위에 띄운다.
- **아이템 끌어다 놓는 영역**: 플레이어 그림의 화면 사각형 + 여유 40px(`Player Item User`의 Drop Padding Pixels).
- **화살 나오는 자리**: A-3(피격 판정)의 중심. 피격 판정이 없으면 플레이어 그림의 중심.
- ⚠ 자동이 아닌 것: 피격 판정(A-3)은 **처음 만들 때만** 그림을 보고 크기를 정한다. 그림을 바꿔도 따라가지 않는다.

## 맞춘 뒤 확인

1. 벽·상자에 붙어 걸어 본다 — 발이 벽에 닿는 느낌이 그림과 맞는가(A-2, C-1, C-2).
2. 적의 접촉 구역에 몸이 겹칠 때 맞는가, 겹치지 않았는데 맞지 않는가(A-3, B-2).
3. 활을 쏴서 화살이 몸 한가운데에서 나오고 적 몸에 맞는가(A-3, A-5, B-1).
4. 근접 베기의 노란 상자가 그림의 칼 휘두르는 범위와 맞는가(A-4, E-1).
5. 아이템·체크포인트에 다가갔을 때 줍는 거리와 닿는 범위가 자연스러운가(A-6, C-3, C-4).

## 목록에 넣는 규칙

- 새 콜라이더, 또는 **그림 크기에 맞춰 손으로 정해야 하는 오프셋·크기·반지름**(판정 상자, 센서 범위, 머리 위 높이 등)을 만들면 이 표에 한 줄을 추가한다. 적을 때 "어디(오브젝트/컴포넌트), 고칠 값, 현재 값, 맞추는 기준"을 쓴다.
- 코드가 그림에서 읽어 **자동으로** 정하는 값은 위 "자동으로 맞춰지는 것"에 적는다.
- 위치나 크기를 고친 뒤에는 "현재 값"과 맨 위의 기준 날짜를 갱신한다.
