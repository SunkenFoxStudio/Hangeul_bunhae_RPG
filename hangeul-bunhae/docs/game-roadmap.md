# 한글 RPG — 탑뷰 액션 RPG 로드맵

인벤토리(단어 카드) 시스템은 거의 완성되어 있고, 이제 그 위에 올릴 **탑뷰 실시간 액션 RPG**(젤다의 전설식 전투)를 만든다.
이 문서는 만들 것의 목록과 확정된 결정을 적고, 단계가 끝날 때마다 갱신한다. 구조/세부는 `unity-architecture.md`(인벤토리, §13 플레이어)에 쓴다.

## 확정된 결정 (2026-10-14)
- **전투**: 턴제가 아닌 실시간 액션. 공격은 **4방향**(근접 베기가 기본).
- **체력**: 하트처럼 **정수 값**(`int`)에서 1, 2씩 깎는 방식. HUD는 하트 아이콘이고 **하트 한 칸 = 체력 2**(반 칸 표시).
- **일시정지**: 인벤토리를 열면 **게임 시간이 멈춘다**(`Time.timeScale = 0`). 단 **가방 흔들기 물리는 멈추지 않고 동작**한다(독립 물리 씬을 `unscaledDeltaTime`으로 직접 진행). 구현은 `GamePause`(`unity-architecture.md` §13.8a).
- **죽으면** 체크포인트로 돌아간다(체크포인트 오브젝트에 닿으면 저장, 없으면 시작 위치).
- **맵 구조**: 아직 정하지 않는다. 우선 **단순한 잔디밭 필드** 하나로 개발한다.
- **애니메이션**: 지금은 코드로 프레임을 재생하는 `PlayerSpriteAnimator`이고, **나중에 안정성을 위해 유니티 Animator로 바꾼다**(상태 코드는 `IPlayerAnimator`로만 접근해 교체할 수 있게 해 둠, 설계 문서 §13.8f).
- **그래픽**: 사용자가 준비한 에셋을 쓴다(공격 모션/적 스프라이트 등은 준비되는 대로). 현재 캐릭터 스프라이트는 방향별 첫 프레임뿐이라 **사실상 애니메이션이 없다** — 동작 타이밍은 프레임 수가 아니라 시간(초)으로 정하고, 그래픽은 슬롯에 나중에 넣는다.
- **공격 키**: 마우스 왼쪽 클릭. 게임패드는 나중에 다시 정한다.
- **적 접촉 피해**: 적 몸통에 닿으면 피해를 입는다(기본 1, 적마다 인스펙터에서 조절·끌 수 있음).
- **적**: 샘플 1종부터. 플레이어와 같은 방식의 **단순한 FSM**(`FSM/StateMachine` 재사용)이면 충분하다.
- 인벤토리에서 미뤄 둔 것(Y 정렬, 세이브 구조·슬롯, 주운 아이템 유지, 키 아이템, 카드 겹침 개수 표시)은 해당 단계에서 다시 꺼낸다.

## 확정된 결정 (2026-10-15) — 아이템 사용
- **종류는 DB 카테고리로 정한다**: `무기` / `방어구` / `음식` 카테고리 단어가 각각 그 종류(별도 종류 필드는 만들지 않는다). 합성 단어는 본체의 카테고리를 따른다.
- **표시와 사용은 가방 모드에서만**: 조립 모드는 조립만 하고 완성 글로우만 보인다. 가방 모드에서 완성된 무기/방어구/음식 단어는 **테두리 + 종류 이름표**가 보이고, **플레이어에게 드래그**해서 쓴다.
- **무기**: 드래그하면 장착/해제(슬롯 하나). 카드는 인벤토리에 남고, 장착 표시는 굵은 테두리 + 오른쪽 아래 체크 배지. 장착한 단어가 깨지면 자동 해제. **장착하지 않으면 공격 불가.**
- **음식**: 드래그하면 먹고 단어 카드가 모두 사라진다. 체력이 가득 차 있으면 먹지 않고 제자리로.
- **방어구**: 지금은 라벨 표시만. 슬롯·장착·효과는 나중에.
- 무기별 수치, 원거리 무기는 **무기 장착 구현을 확인한 뒤** 다시 이야기한다.

## 현재 있는 것
플레이어 이동(Rigidbody2D)과 FSM(Idle/Move/Interact/Locked), 4방향 스프라이트 애니메이션, 상호작용 센서·안내 UI, 맵 아이템 줍기,
Cinemachine 카메라, 인벤토리·단어 카드·아이템 DB(카테고리/접두어), 가방 흔들기 물리, 일시정지(`GamePause`).

## 만들 것

### A. 전투 기반
- 레이어/충돌 설정(Player, Enemy, PlayerAttack, EnemyAttack, World)
- 피해 처리 구조: `Health`(int), `IDamageable`, `DamageInfo`(피해량, 공격자, 속성, 밀어내기)
- 맞았을 때: 경직, 밀려남, 무적 시간

### B. 플레이어 전투
- 공격 상태(4방향 근접 베기, 공격 판정 범위), 구르기/회피(Dash 스프라이트 활용), 죽음·체크포인트 부활

### C. 적
- 적 기본 구조(FSM: 대기 → 추적 → 공격 → 피격 → 죽음), 감지 범위, 공격 전조
- 샘플 1종(근접형) → 원거리형 + 투사체(풀링) → 돌진형
- 죽을 때 아이템 떨어뜨리기(단어 카드 아이템)

### D. 전투 연출 / HUD
- 맞았을 때 번쩍임, 히트스톱, 화면 흔들림, 피해 표시, 효과음, 입자 효과
- 체력 HUD(하트), 게임오버 화면

### E. 아이템과 카드의 전투 연결 (이 게임의 특징)
- 단어 → 아이템 정의(종류/수치/효과), DB 관리 씬에 항목 추가
- 무기 단어를 플레이어에 드래그해 장착, 음식은 드래그해 회복
- 접두어·속성(예: 불화살)이 효과에 반영, 활/화살 같은 원거리 무기, 장비 슬롯

### F. 월드와 콘텐츠
- 방/씬 전환(맵 구조 결정 후), 카메라 영역 제한, 열쇠·키 아이템 구역, 부술 수 있는 물건, 상자, 스위치
- NPC 대화(한글)·퀘스트 플래그, Y 정렬

### G. 시스템
- 게임 상태 관리 확장(대화/메뉴 정지), 세이브(슬롯·월드 상태), 오디오, 설정 메뉴

## 진행 순서 (수직 슬라이스)
0. ✅ 일시정지(`GamePause`) + 흔들기 물리를 정지와 무관하게 동작
1. ✅ A: 레이어와 피해 구조(`Health`/`DamageInfo`/`IDamageable`, 피격·무적·밀려남·사망, 전투 레이어 메뉴, 테스트용 `DamageZone`) — 설계 문서 §13.8b
2. ✅ B: 플레이어 공격(마우스 왼쪽 클릭, 4방향 근접, 그래픽 슬롯, 훈련 인형) — 설계 문서 §13.8c
3. ✅ C: 적 1종(근접 추격형 슬라임 샘플: FSM, 접촉 피해, 밀려남, 죽음, 드롭 슬롯) — 설계 문서 §13.8d
4. D 일부: 체력 HUD(하트 한 칸 = 체력 2), 맞았을 때 효과(번쩍임·깜빡임·히트스톱·화면 흔들림), 체크포인트 부활(화면 페이드) — 구현함, 확인 대기 — 설계 문서 §13.8e
4b. 플레이어 애니메이션(프레임 자동 채우기, 공격/피격 모션을 시간표에 맞춰 재생, 죽음 모션) — 구현함, 확인 대기 — 설계 문서 §13.8f
5. (보류) B: 구르기 — 당장은 만들지 않는다(필요할 때 다시 정함)
6. E 일부: 무기 단어 장착(플레이어에게 드래그, 무기 없으면 공격 불가) + 음식 먹기 + 방어구 라벨 표시 — 구현함, 확인 대기 — 설계 문서 §13.7c
6b. E 일부: 단어별 상세 수치(무기: 피해량·밀어내기·경직·범위·시간, 음식: 회복량) — DB 관리 씬의 "상세 수치 열기" 패널 + 게임 적용 — 구현함, 확인 대기 — 설계 문서 §13.7d
6c. (후속) E: 접두어·속성이 수치에 더해지는 규칙(합성 단어는 지금 본체 수치를 따름), 방어구 장착·슬롯·효과
7. C: 원거리 적 + 투사체, 활과 화살
8. F, G: 방 전환, 열쇠, 일시정지 메뉴, 세이브
